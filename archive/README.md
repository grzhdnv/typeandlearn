# Archive

This directory preserves historical TypeAndLearn material that is not part of the
current runtime or authoritative roadmap.

- `backend/` — legacy data and migration experiments
- `experiments/` — standalone prototypes and exploratory scripts
- `legacy/` — the pre-v2 command-line implementation
- `plans/` — superseded planning documents retained for historical context

Current development guidance lives in the root `README.md`, `docs/architecture.md`,
and `docs/roadmap.md`.
