# TypeAndLearn Frontend

SolidJS frontend organized by feature:

- `src/app` — application shell
- `src/features/texts` — text fetch/upload workflows
- `src/features/typing` — typing interaction UI
- `src/shared/api` — HTTP helpers
- `src/shared/types` — frontend contract types

## Run

```bash
npm install
npm run dev
```

## Checks

```bash
npm run check
```
